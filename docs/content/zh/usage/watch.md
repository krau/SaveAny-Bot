# 监听聊天

{{< hint warning >}}
需要启用 UserBot 集成.
{{< /hint >}}

你可以监听指定聊天中的消息, 并按照存储规则自动保存到默认存储. 也可以添加过滤器, 只保存匹配的消息.

发送 `/watch` 管理监听的聊天:

- **添加监听** — 显示添加聊天的语法
- **监听列表** — 列出正在监听的聊天, 可以逐项停止
- **通知开关** — 开关所有监听聊天的任务通知
- **同步对话** — 将 UserBot 的对话列表同步到 peer 缓存

开始监听:

```
/watch <聊天ID/用户名> [过滤器]
```

停止监听: 从 `/watch` 进入 **监听列表**, 选择对应聊天.

过滤器类型:

## msgre

按消息文本正则匹配, 例如:

```
/watch -1002229835658 msgre:.*hello.*
```

这会监听 ID 为 `-1002229835658` 的频道, 只保存文本包含 `hello` 的消息. 用户私聊使用正数 ID，普通群使用负数 ID，超级群和频道使用 `-100...`。

## 任务通知

所有用户默认关闭任务通知. 使用 `/watch` → **通知开关** 开启后, Bot 会为监听到的每条消息发送一条通知, 并更新下载进度和最终结果; 再次选择即可关闭.

通知由 Bot 发送到你与它的私聊中. 该开关按用户生效, 不区分具体监听的聊天.
