    监听聊天

    • msgre
    • 任务通知

    监听聊天 #

    需要启用 UserBot 集成。

    可监听指定聊天中的新消息，支持按过滤器筛选并依照存储规则自动保存。

    发送 /watch 管理监听聊天：

    • 添加监听 — 显示添加聊天的语法
    • 监听列表 — 列出正在监听的聊天，可逐项停止
    • 通知开关 — 开关所有监听聊天的任务通知
    • 同步对话 — 将 UserBot 的对话列表同步到 peer 缓存

    开始监听：

    /watch <聊天ID/用户名> [过滤器]

    停止监听：在 /watch 的“监听列表”中点击对应聊天即可停止。

    过滤器类型:

    msgre #

    按消息文本正则匹配，例如：

    /watch -1002229835658 msgre:.*hello.*

    这会监听 ID 为 -1002229835658 的频道，只保存文本包含 hello 的消息。用户私聊使用正数 ID，普通群使用负数 ID，超级群和频道使用 -100...。

    任务通知 #

    任务通知默认关闭。在 /watch 中切换“通知开关”开启后，Bot 会在私聊中实时推送监听到的消息进度与保存结果。此开关按用户生效，作用于该用户的所有监听聊天。再次点击即可关闭。
